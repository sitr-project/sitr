# سِتر | SITR

موقع عربي متجاوب قابل للتثبيت كواجهة ويب (PWA)، وإضافة تجريبية لمتصفحي Chrome وEdge على الكمبيوتر. صورة الشعار التي زوّد بها صاحب المشروع مستخدمة في واجهة الموقع وأيقونات التثبيت.

## ما يعمل

- واجهة الموقع RTL ومتجاوبة.
- تثبيت واجهة الموقع كـPWA على Android، وعلى الكمبيوتر بالمتصفحات الداعمة؛ وعلى iPhone يمكن إضافتها إلى الشاشة الرئيسية عبر Safari.
- إضافة متصفح تجريبية تسمح للمستخدم باختيار مواقع ويب وتغبيش الصور والفيديو فيها، مع درجة من 1 إلى 24 بكسل وزر تشغيل/إيقاف.
- إعدادات الإضافة محفوظة محليًا في مساحة الإضافة. صلاحية الوصول اختيارية وتُطلب للنطاقات المختارة فقط.

## حدود مهمة

- تثبيت PWA يضيف واجهة الموقع وأيقونته فقط، وليس APK ولا تطبيق Android أصليًا؛ لا يستطيع التحكم بتطبيقات أخرى.
- الإضافة تعمل على صفحات الويب في Chrome/Edge للكمبيوتر. لا تعمل داخل تطبيقات الهاتف، ولا على Chrome للجوال أو Safari.
- الخيار الوحيد العامل هو «كل الصور والفيديو». خيار «الأشخاص فقط» غير متاح حتى يتوفر كاشف أشخاص محلي موثوق؛ لا يتم تخمين جنس الأشخاص من الصور.
- التغبيش يطبّق CSS على الصور والفيديو وبعض عناصر الرسم داخل النطاق المحدد، وليس على محتوى بعينه. قد لا تتأثر بعض الوسائط داخل shadow DOM أو الصور الخلفية أو الإطارات الخارجية.
- لم تنشر الإضافة في متاجر المتصفحات؛ التثبيت يدوي تجريبي.

## تجربة الموقع محليًا على Windows

ثبّت Python 3 إذا لم يكن مثبتًا. افتح PowerShell داخل مجلد المشروع وشغّل:

```powershell
cd "C:\Users\Fr\Desktop\مشروع ستر"
py -m http.server 8000
```

افتح `http://localhost:8000`. أوقف الخادم بـ `Ctrl+C`. يلزم localhost أو HTTPS لميزات PWA.

## تثبيت واجهة الموقع كـPWA

- Android: افتح الموقع في Chrome، ثم القائمة ⋮ > «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- iPhone/iPad: افتح في Safari، اضغط مشاركة > «إضافة إلى الشاشة الرئيسية».
- الكمبيوتر: في Chrome أو Edge اختر رمز التثبيت بجانب العنوان، أو «تثبيت هذا الموقع كتطبيق» من قائمة المتصفح.

واجهة PWA لا تطبق تغبيشًا على تطبيقات الجوال. إعدادات التغبيش الحقيقية موجودة في إضافة المتصفح للكمبيوتر.

## تثبيت إضافة المتصفح

راجع [دليل الإضافة](./browser-extension/README.md). باختصار:

1. نزّل ZIP الإضافة من زر التنزيل في الموقع وفك ضغطه.
2. افتح `chrome://extensions` أو `edge://extensions` وفعّل **Developer mode / وضع المطوّر**.
3. اختر **Load unpacked / تحميل إضافة غير معبأة** وحدد المجلد الذي يحتوي `manifest.json` مباشرة.
4. افتح ستر من قائمة الإضافات، اختر «كل الصور والفيديو»، اضبط الشدة والمواقع، ثم احفظ وشغّل ووافق على صلاحية النطاقات المختارة.
5. حدّث صفحات المواقع المفتوحة. يمكن تغيير الدرجة أو إيقاف التأثير لاحقًا من نافذة الإضافة.

## الاختبار

1. اختبر تثبيت PWA من متصفح يدعمها وتحقق من ظهور أيقونة ستر.
2. ثبّت الإضافة في ملف متصفح تجريبي واختر نطاقًا تثق به.
3. شغّل التغبيش؛ افحص ظهور الصور والفيديو بعد تحديث الموقع، ثم غيّر الشدة وأوقف الميزة.
4. تحقق أن موقعًا غير محدد لا يتأثر، وأعد تشغيل المتصفح للتحقق من بقاء التفضيلات.

تم التحقق من بنية حزمة الإضافة وسلامة ملف ZIP، ومن منطق إنشاء/إزالة تسجيل السكربتات بحقن واجهات محاكاة. لم يتم التحقق من التثبيت على Chrome حقيقي في بيئة البناء.

## النشر

الموقع وPWA ملفات ثابتة؛ يمكن نشرها على GitHub Pages أو Cloudflare Pages. ارفع الملفات المحدّثة والمجلدات كلها إلى المستودع. بعد اكتمال النشر، يحتوي زر تنزيل الإضافة على ملف ZIP جديد.

## تطبيق Android أصلي مستقبلًا

لا يوجد APK الآن. VPN محلي يمكنه تصفية بعض النطاقات، لكنه لا يرى محتوى الصور والفيديو داخل التطبيقات المشفرة. تقنيات إمكانية الوصول لا تمنح ضمانًا لقراءة كل محتوى التطبيقات، ولها قيود خصوصية وسياسات متجر. يلزم بناء التطبيق الأصلي واختبار كل صلاحية وميزة قبل الادعاء بالحماية داخل تطبيقات التواصل.
