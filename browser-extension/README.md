# إضافة سِتر التجريبية لمتصفحات Chrome وEdge

هذه إضافة Manifest V3 للكمبيوتر. عند التشغيل تُغَبّش عناصر الصور والفيديو داخل **صفحات المواقع المختارة**، مع درجة تغبيش قابلة للتعديل. لا تحلل محتوى المنشورات ولا تعمل على Chrome للجوال أو داخل تطبيقات الهاتف أو Safari.

## التثبيت على Windows

1. نزّل ملف إضافة المتصفح ZIP من زر التنزيل في موقع ستر، ثم فك الضغط إلى مجلد.
2. افتح Google Chrome واكتب `chrome://extensions` في شريط العنوان. في Microsoft Edge استخدم `edge://extensions`.
3. فعّل **Developer mode / وضع المطوّر**.
4. اضغط **Load unpacked / تحميل إضافة غير معبأة**.
5. اختر المجلد الذي فككت إليه الملف. يجب أن يكون `manifest.json` ظاهرًا مباشرة داخل المجلد المختار.
6. ثبّت الإضافة في شريط المتصفح عبر رمز القطعة، ثم افتح **ستر | SITR**.
7. اختر نمط «كل الصور والفيديو» واضبط درجة التغبيش.
8. اختر المواقع واضغط **حفظ الإعدادات**، ثم **تشغيل التغبيش**. وافق على صلاحية المواقع التي اخترتها عندما يطلبها المتصفح.
9. حدّث أي صفحة مختارة كانت مفتوحة قبل تشغيل الإضافة. أوقف التغبيش من نافذة الإضافة للعودة.

لا تختَر مجلدًا أعلى أو فرعيًا؛ اختر المجلد الذي يحتوي `manifest.json` مباشرة.

## ما الذي تفعله وما الذي لا تفعله؟

- يعمل التغبيش محليًا في المتصفح، من دون خادم أو إرسال سجل التصفح أو الصور.
- تضيف الإضافة تأثير CSS إلى عناصر `img` و`video` و`canvas` و`svg image` داخل النطاق المختار ونطاقاته الفرعية.
- اختيار YouTube أو TikTok أو Instagram أو X يغبّش كل الصور والفيديو في نسخة الموقع داخل المتصفح؛ لا يغبّش منشورات بعينها ولا يحجب الموقع كاملًا.
- درجة التغبيش بين 1 و24 بكسل ويمكن تعديلها من نافذة الإضافة. إذا لم يتغير تبويب مفتوح، حدّث الصفحة.
- خيار «الأشخاص فقط» غير متاح. لا نستخدم تخمينًا عن جنس الأشخاص؛ يتطلب الخيار كاشف أشخاص محليًا دقيقًا لم يُبنَ بعد.
- متاح في مواقع الويب على Chrome وEdge للكمبيوتر. لا يعمل داخل تطبيقات Android أو iPhone، ولا على Safari أو Chrome للجوال.
- التخزين محلي في `chrome.storage.local`. إزالة الإضافة تحذف إعداداتها.

تطلب الإضافة `scripting` و`storage`. صلاحية المواقع اختيارية وتُطلب فقط للنطاقات التي يحددها المستخدم. يحقن السكربت نمط CSS في تلك المواقع لإضافة التغبيش. الشفرة متاحة للمراجعة ضمن مجلد الإضافة.

## الاختبار

1. ثبّت الإضافة في ملف متصفح تجريبي، واختر موقعًا أو نطاقًا تجريبيًا تثق به.
2. شغّل التغبيش ووافق على صلاحية النطاق، ثم حدّث تبويب الموقع.
3. تحقق من تغبيش الصور والفيديو، ومن بقاء النصوص والعناصر الأخرى واضحة.
4. غيّر شدة التغبيش واحفظ، وتحقق من تحديث الصفحة المفتوحة.
5. أوقف التغبيش، وتحقق من زوال التأثير.
6. أعد تشغيل المتصفح وتحقق من بقاء الإعدادات.

هذه نسخة تجريبية محملة يدويًا، وليست منشورة في Chrome Web Store أو Microsoft Edge Add-ons. لا تُثبّت إلا برمجيات تثق بمصدرها وتفهم صلاحياتها.
