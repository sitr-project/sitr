# إضافة سِتر التجريبية لمتصفحات Chrome وEdge

هذه إضافة Manifest V3 للكمبيوتر. عند التشغيل تمنع فتح **النطاقات المختارة بالكامل** (مثل youtube.com)، ولا تحلل محتوى المنشورات. لا تعمل على Chrome للجوال، أو داخل تطبيقات الهاتف، أو على Safari.

## التثبيت على Windows

1. نزّل ملف إضافة المتصفح ZIP من زر التنزيل في موقع ستر، ثم فك الضغط إلى مجلد.
2. افتح Google Chrome واكتب `chrome://extensions` في شريط العنوان. في Microsoft Edge استخدم `edge://extensions`.
3. فعّل **Developer mode / وضع المطوّر**.
4. اضغط **Load unpacked / تحميل إضافة غير معبأة**.
5. اختر المجلد الذي فككت إليه الملف. يجب أن يكون `manifest.json` ظاهرًا مباشرة داخل المجلد المختار.
6. ثبّت الإضافة في شريط المتصفح عبر رمز القطعة، ثم افتح **ستر | SITR**.
7. اختر المواقع واضغط **حفظ المواقع المختارة**، ثم **تشغيل الحماية**.
8. اختبرها بفتح النطاق المختار في تبويب جديد. من المتوقع أن يمنع المتصفح تحميل الصفحة. أوقف الحماية من نافذة الإضافة للعودة.

لا تختَر مجلدًا أعلى أو فرعيًا؛ اختر المجلد الذي يحتوي `manifest.json` مباشرة.

## ما الذي تفعله وما الذي لا تفعله؟

- تعمل قواعد الحجب في المتصفح نفسه، من دون خادم أو إرسال سجل التصفح.
- تحجب الإضافة انتقالات الصفحات الرئيسية إلى النطاق المختار ونطاقاته الفرعية. لا تضمن حجب محتوى مضمنًا داخل موقع آخر.
- اختيار YouTube أو TikTok أو Instagram أو X يحجب الموقع بكامله، ولا يصنف صورًا أو فيديوهات أو منشورات داخل الموقع.
- لا تراقب تطبيقات الهاتف، ولا تحجبها، ولا توفر ملف APK.
- التخزين محلي في `chrome.storage.local`. إزالة الإضافة تحذف إعداداتها.

الإضافة تتطلب صلاحيتَي `declarativeNetRequest` لتطبيق قواعد الحجب و`storage` لحفظ اختيار المستخدم. قواعد الحجب تطبق فقط على النطاقات التي أدخلها المستخدم. الشفرة متاحة للمراجعة ضمن مجلد الإضافة.

## الاختبار

1. ثبّت الإضافة في ملف متصفح تجريبي، واختر `example.com` أو أحد المواقع المعروفة.
2. شغّل الحماية، وافتح النطاق المحدد؛ ينبغي أن يمنع المتصفح تحميل الصفحة الرئيسية.
3. افتح نطاقًا آخر غير محدد وتأكد أنه لا يتأثر.
4. عطّل الحماية، وأعد محاولة فتح الموقع المحجوب.
5. أعد تشغيل المتصفح وتحقق من استمرار الإعدادات والحالة.

هذه نسخة تجريبية محملة يدويًا، وليست منشورة في Chrome Web Store أو Microsoft Edge Add-ons. لا تُثبّت إلا برمجيات تثق بمصدرها وتفهم صلاحياتها.
